## 0. 헤드라인 판정

**추정기 코어와 검증 문화는 견고하다. 결함은 코어가 아니라 (a) 자기 검증 결과를 안 따르는 주변 항들, (b) 확신을 과장하는 표시층, (c) 검증 하네스 자체의 방법론 허점에 있다.**

- 건전: 계층적 κ-수축(κ=40 ≈ 실측 EB 최적 37), posterior-mean 랭킹, per-champ 적응형 이전패치 블렌딩(power prior), 저작 패치노트 기반 리셋 배선, 피어리스 풀 산술, 검증 실패 항의 실제 제거 이력(W_MU_DIRECT=0).
- 결함: ~20개 스코어링 항 중 **결과-검증된 것은 2개**(base_lane, 숙련)뿐인데, 검증 실패/미검증 항들이 랭킹 마진(0.01–0.04)을 일상적으로 결정. 신뢰 서열이 검증 기록과 **정반대**로 실현된 지점(ai_prior)이 존재. 티어 표시는 통계적으로 지지 불가능한 확신을 전달.

## 2. 통합 결함 목록 (심각도순, 5개 보고서 dedup + 코드 재검증 완료)

### F1. ai_prior — 신뢰 서열 역전 (가장 심각한 설계 결함)

- **설계 드리프트 실증**: 45.4% 기각(53e58cf, 06-13 03:18)과 PLAN.md 승인 스코프("통계 0 챔프만, **15판 페이드**") 1시간 뒤 커밋 75cdac8이 K=10 무게이트로 완화 — deny/steal과 같은 커밋인데 이것만 리뷰에서 생존, PLAN.md 미갱신.
- 부수: AI_PRIOR static이 패치 경계에서 리셋 안 됨(`lib.rs:1288`); p 중심화는 우연히 성립(밴스캔 분포 -0.021..+0.045 near-centered — 명시화 필요); 45.4%는 n=3293에서 ~5σ 아래 = 실제 역상관.

## 3. 통합 개선 로드맵

> 원칙(PLAN.md:99 유지): 점수 모델 변경 = 백테스트 수치 동반. 단, **이미 증거가 있는 것**(검증 실패 기록·실측 반증·표시 정직성)은 하네스 없이 집행 가능.

### Step 0 — 하네스부터 (모든 가중치 변경의 전제)
1. `validate-terms` 폴드를 `i%5` → **rolling-origin**(시간 컷)으로. 기존 판정 전부 배포 조건에서 재채점.
2. `probe\DEBUG_DUMPS` 마커 생성 후 1세션 플레이 → 최신 2패치 포함 ~5,000판 재캡처.
3. 하네스에 **프로덕션 수학 이식**(κ40/κ20, 0.35 블렌드, 저작 리셋) — 지금은 κ8로 다른 모델을 검증 중.
4. 사전등록 6모델 비교 + 부트스트랩 CI(⑤ 프로토콜 A). +0.5~1%p급 효과는 이 규모에서 **측정 불가**임을 명시 — "미입증, 코스메틱 예산"으로 강등.
